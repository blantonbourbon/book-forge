# Product

## Register

product

## Users

Anyone converting web pages to EPUB — casual readers saving articles for e-readers, developers grabbing documentation, power users crawling sites. No account, no friction. The interface should serve both first-time visitors and returning users equally well: clear defaults, obvious primary action, and no unnecessary steps.

## Product Purpose

Convert a single HTML page or a scoped same-site crawl into a downloadable EPUB file. Success means: paste a URL, click one button, get a file. Everything else supports that core loop.

## Brand Personality

Clean and invisible. The tool disappears into the task. Terminology and affordances feel native, not invented. Confidence through clarity, not decoration.

## Anti-references

- Generic SaaS landing gradients (purple-blue, glassmorphism, backdrop-blur cards)
- Over-decorated tool UIs with invented affordances
- Terminal/CLI aesthetic (too raw — this is still a web tool)
- Hero-metric templates, identical card grids, gradient text

## Design Principles

1. **One primary action.** The form has one job: start a conversion. Everything else is secondary or hidden until relevant.
2. **Say it once.** No restated headings, no redundant help text, no intro paragraphs that repeat the title.
3. **Earned color.** Color carries meaning (states, progress, primary action), not decoration.
4. **Warm utility.** The "forge" metaphor suggests warmth and craft — not cold industrial, not SaaS-generic.

## Accessibility & Inclusion

WCAG 2.1 AA. All interactive elements have visible focus indicators. Form errors are announced via live regions. Color is never the sole indicator of state.
